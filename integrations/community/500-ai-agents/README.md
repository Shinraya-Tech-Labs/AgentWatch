# Panopti Pre-Execution SQL Guardrail Agent

An autonomous agent interacting with a database behind Panopti's pre-execution guard. It intercepts adversarial SQL injections (`DROP TABLE users;`), enforces zero-latency runtime vetoes, and generates cryptographic Merkle witness audit seals.

## Quick Start
```bash
pip install -r requirements.txt
python agent.py
```
